# تطبيق By Hex

تطبيق محرر Hex متعدد المنصات يعمل على Android وiOS وسطح المكتب، يوفر واجهة سهلة الاستخدام وميزات متقدمة لتحرير وتحليل الملفات الثنائية.

## الميزات الرئيسية

### 1. محرر Hex أساسي
- عرض الملفات بتنسيق Hex وASCII/UTF-8 جنبًا إلى جنب
- البحث عن قيم Hex أو نصوص
- تحرير وتعديل البايتات يدويًا وحفظ التغييرات
- دعم الملفات الكبيرة مع التحميل الجزئي

### 2. المصادقة والتخزين
- تسجيل الدخول وإنشاء الحسابات باستخدام Firebase
- تخزين سحابي للملفات باستخدام Firebase Storage
- مزامنة الملفات بين الأجهزة المختلفة

### 3. الأمان والفحص
- فحص تلقائي للملفات عند فتحها
- تكامل مع VirusTotal لفحص الملفات
- عرض نتائج الفحص في واجهة التطبيق

### 4. الإشارات المرجعية
- إضافة إشارات مرجعية للبايتات المهمة
- التنقل السريع بين الإشارات المرجعية
- تمييز بصري للإشارات المرجعية في عرض محرر Hex

### 5. تصدير التقارير
- إنشاء تقارير PDF شاملة عن الملفات
- تخصيص محتويات التقرير
- تضمين معلومات الملف، نتائج الفحص، وسجل التعديلات

### 6. مقارنة الملفات
- مقارنة بين ملفين بتنسيق Hex
- تمييز الاختلافات بصرياً
- تحليل التغييرات بين الإصدارات

## متطلبات النظام

- **Android**: الإصدار 5.0 (Lollipop) أو أحدث
- **iOS**: الإصدار 12.0 أو أحدث
- **سطح المكتب**: Windows 10/11، macOS 10.15+، Linux (Ubuntu 18.04+)

## التثبيت

### للمطورين
1. تأكد من تثبيت Flutter SDK (الإصدار 3.3.0 أو أحدث)
2. استنسخ المستودع: `git clone https://github.com/yourusername/by_hex.git`
3. انتقل إلى دليل المشروع: `cd by_hex`
4. قم بتثبيت التبعيات: `flutter pub get`
5. قم بتشغيل التطبيق: `flutter run`

### للمستخدمين
- **Android**: قم بتنزيل التطبيق من Google Play Store
- **iOS**: قم بتنزيل التطبيق من App Store
- **سطح المكتب**: قم بتنزيل الإصدار المناسب لنظام التشغيل الخاص بك من صفحة الإصدارات
